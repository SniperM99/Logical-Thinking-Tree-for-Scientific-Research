# V1.1 实现范围与后续里程碑

| 里程碑 | 已实现并可运行 | 后续工作 |
|---|---|---|
| 01 研究图核心 | Java 最终写入、PostgreSQL 持久化、节点与关系、问答证据、会话锚点、路径上下文、审核和版本 | 分空间并发、数据库层汇合约束、多人权限、证据导入 |
| 02 智能生长 | Python 独立服务、一主多辅坐标、DeepSeek 自动思想提取与意图归一、明确意图聚类、增量去重、独立思想生成、弱强关联 | 自动提取质量校准、语义密度聚类、科研样本校准、非叶直接总结更新机制 |
| 03 自然研究树 | React / TS、向上曲线枝干、左右键、档案和问答定位、候选方向、审核预览 | 大规模 Canvas / WebGL、稳定布局评分、疏密算法、自动剪枝建议 |

| 05 结构治理 | 手动移动、同父叶合并、共同分支、冻结隐藏、独立移植、路径 Markdown、最近结构撤销 | 跨父叶合并预览、复杂差异恢复、跨边界来源移植策略 |

Redis / MinIO 目前为基础设施部署配置。真实模型通过环境变量接入；没有密钥时页面接受人工问答，不伪造大模型回答。设备协议已在本机独立进程执行验收，其他实体设备需要部署 Agent 后实际联调。

后续优先顺序：自动思想提取与语义校准 → 任务工作流和产物存储 → 并发与权限 → 自然布局评分。外部 Codex / Claude 操作感知继续后置。结构模型不因这些模块尚待完善而退化为普通父子树。
