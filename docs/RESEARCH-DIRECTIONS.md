# 研究方向与具体问题的两层生长判断

2026-10-10 修订。理论框架 V1.0、V1.1 原文件保留。

问题：只有 same_intent（相同具体问题）才能生长，导致“世界模型研究方向”与“哲学认知世界模型谱系”虽相似度进入候选范围，却只被判 related。不同子问题可支持共同研究方向，不能因此直接合并其具体问题。

新增方向簇 research_direction，与原有 semantic 具体问题簇分别记录。只使用不同问答的主思想；同空间、同固定起始节点、同编码模型，高维余弦达到候选阈值后，在原有候选意图判定请求中同时判断共同方向。原始问题必须明确以同一具体研究对象为主要目标，至少一轮是方向概览、理论谱系、整体解读或应用探索。回答中偶然提到同名对象、辅助思想、宽泛领域标签不能作为方向生长依据。

方向分组要求组内每对均有同一方向判断，避免用单个桥接思想串联不同对象。两个不同问答支持的新方向创建方向节点；同起始节点下同名已有方向簇只补充证据。节点保存 research_level=direction、触发来源及原始问答引用。旧具体问题节点不自动移动或合并；方向节点直接研究总结只使用其明确关联问答，不写回祖先。会话锚点和出生坐标不变，历史轮次判断不改写。

新问答的主思想提取保留用户的整体意图，不用回答中的单个争议替代方向概览。回答与思想提取仍是一轮模型调用，候选判定仍按需额外调用，并非每轮固定三次。方向判定缺失字段时明确失败，不能静默当作无方向。

历史问答通过“思想空间 → 重新量化历史问答”补充尚无本版方向判断的主思想对。已有坐标不重复编码；方向判断保存在思想关联，新增方向节点及审计记录保留。后续版本可改进方向标题的别名规范、主思想召回和大规模候选索引。当前 0.60 是待校准候选阈值，二维投影不决定归属。
