# 会话顺序与语义空间驱动的生长归属

> 当前新问答已改为创建前的研究问题归属判断，见 [问答节点归属](QA-NODE-OWNERSHIP.md)。以下保留此前事后归属与批量聚类的设计记录；它不再是新问答默认执行流程，旧结构提案继续可追溯。

2026-10-10 修订，理论框架 V1.0、V1.1 原文件保留。

会话 anchor_id 是永久来源锚点，不是每个新节点的实际父节点。思想出生坐标同样保留。生长归属通过单独的 growth_placement_decision 记录，包含候选、前序证据、模型判断和理由。

候选规则：同一研究空间、同一会话来源锚点可达的有效节点；排除自身及子孙、隐藏/归档/冻结节点。节点已有直接关联主思想时，用主思想首次轮次界定候选前序范围；只有辅助证据时，以最后支持轮次召回候选，再由模型确认真正的展开起点。候选必须有同会话的前序问答。最早辅助提及不等于分支起点。语义得分使用同编码模型下直接证据思想的最大真实高维余弦；结合前序轮次选取最多五个候选。排序暂用 0.7 × 高维相似度 + 0.3 × 前序轮次相对接近程度，属于待校准的召回参数，不是父子关系规则或概率。不能使用二维投影代替真实向量，也不能单凭对话顺序串成链。

AI 收到按轮次排列、截至当前节点最后证据轮次的会话问答片段，以及候选前序证据和相似度。最终采用的祖先证据必须早于正式深入讨论的起点，Java 和 Python 都校验所选轮次，不能使用同轮或未来证据，不发送其他会话、兄弟节点总结或未来问答。分类为 deepen（在既定研究范围内进一步展开）、continue（相同具体问题延续）、switch（独立方向切换）、uncertain（不足以判断）。只有 deepen 且目标是准入候选时才建议父子继承。所有结果经 Java 校验空间、冻结和循环约束。

新创建节点可在同一事务内确定正确的父节点。既有节点只生成 move 结构提案，不静默修改。提案展示前后结构与上下文；研究者在历史面板“审核并执行”。拒绝保留，不反复催促；研究结构变化后，旧预览由版本指纹识别，重新分析可生成新预览并保留旧记录。决定记录本身不绘制为已生效的树枝。

典型例子：世界模型方向概览 → 哲学认知世界模型 → JEPA深入解读 → JEPA应用。顺序建立研究背景，高维思想坐标支持关联，研究逻辑进一步确认 JEPA 是该世界模型讨论的展开。另一段独立的 JEPA 会话不会因为通用知识上有关联就自动移到世界模型下。

调用成本：回答与思想提取保持一次 DeepSeek 调用。具体思想聚类判定按需调用；有前序候选的新生节点或待重新判定节点，再按批次调用生长归属判断。并非所有问答都只消耗一次 API；相同证据与候选已有判定时复用记录。

目前按直接证据思想召回候选，长会话及大规模图还需进一步分层压缩和索引。多会话来源的冲突需要人工审核，不把不同会话当作一个时间序列。
