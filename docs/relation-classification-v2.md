# 循序：关系判别与独立增量生长实验分支

分支：`codex/relation-classification-v2`。

本分支保留科研平台基础功能，重构问答与研究节点的自动归属，并提供独立本地实验工具。当前交互工具运行在 5174，数据与 Java 平台数据库隔离；未将实验算法接入主平台自动生长。平台接入的本地备份不属于此分支提交内容。

## 核心流程

新问答 → 一次生成回答与约80字核心描述 → 局部承接判别 → 轻量空间检索 → 对比局部提案与历史候选 → 追加节点或关联资源。

每条问答在最终归属前都执行检索，包括局部已判为深化、补充、新方向的情况。最终挂根必须解释为何候选没有更直接归属，不能把“局部没有”当作“全空间没有”。有限召回仍可能漏掉真正父节点，不是全空间不存在更直接归属的证明。

## 主要能力

- 新研究空间、从选中节点新建会话、多轮问答及刷新恢复。
- 深化、并列、同问题补充、历史回访、独立方向及域外判别。
- 新节点持久化位置，追加时不改旧节点父边和坐标；不自动重构历史树。
- 同问题补充进入已有节点资源池，待判定内容按AI建议归属暂存。
- 回答先保存，生长失败可单独重试；请求ID避免重复写入。
- 保存局部提案、检索候选、最终理由、增量事件及离线评估报告。

## 技术实现

- DeepSeek 兼容接口与函数结构化输出：回答/描述、局部判别、最终比较，正常一轮通常3次模型请求。
- BGE-small-zh-v1.5：512维语义向量，ONNX INT8 本地CPU推理。
- 中文双字片段/英文词 BM25 与向量余弦，通过 RRF 融合取最多10条问答候选，再补充归属节点和祖先。
- Python/FastAPI 独立服务、SVG 固定坐标展示、本地JSON与原子替换保存。
- 当前检索仍扫描历史索引，独立服务也会重建词法统计；尚非大规模ANN或高并发实现。

## 代码入口与运行

- `experiments/qa_space/standalone_lab.py`：独立服务、持久化、问答与生长。
- `experiments/qa_space/standalone_lab_ui.js`：会话与问答界面。
- `experiments/qa_space/incremental_growth.py`：共享增量规则及离线顺序实验。
- `experiments/qa_space/README.md`：完整实验说明。

准备好本地 AI Python 环境、模型与 `ai-engine/.env` 中的 `XUNXU_` 配置后运行：

```sh
scripts/run-standalone-lab.sh
```

打开 `http://127.0.0.1:5174/research-tree-incremental.html`。该服务需要此前生成的 `.runtime/exports/research-tree-incremental.html` 模板；源码克隆并不是一键运行包，相关生成脚本见实验目录。5174只允许一个服务占用。

私有状态保存在 `.runtime/standalone-lab/state.json`。原始实验数据、导出HTML、模型、运行环境、密钥不进入Git；密钥仅服务端读取。

## 验证与限制

```sh
.runtime/ai-venv/bin/python -m unittest discover -s experiments/qa_space -p 'test_*.py'
```

当前25项测试通过，覆盖增量位置稳定、幂等、失败恢复、挂根检查，以及非根局部深化仍须检索比较。真实模型问答与浏览器恢复也已验证。

测试通过说明实现行为符合规则，不代表父子语义判别正确。早期严格增量实验86条原表父边只匹配25条；之后加入的每问检索规则尚未完成全量独立精度验证。数据曾用于调试，不是留出测试集。原始导入数据没有真实会话ID，新交互会话有独立ID。历史错误边不会随新规则自动修复。

本分支用于可观察的算法实验与交互验证，尚不宜宣称生产级准确率或鲁棒性。
