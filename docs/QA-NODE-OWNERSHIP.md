# 问答对主要归属与生长校验

每条已保存且有主思想的问答对拥有一个主要研究节点。先复用同空间、同研究问题的已有节点，或已有主思想正式证据关联的具体问题节点；没有对应节点则根据本轮主思想创建节点。辅助思想只保存在问答分析和思想空间中，不生成节点，也不挂靠其他节点。节点主要归属只使用主思想；同意图聚类用于复用已有主要节点，不再独立创建额外思想簇节点或方向节点。

主要归属保存在 `qa_primary_node` 关系中，原始问答、会话起始节点与出生坐标不改写。问答 API 与研究空间视图提供 `primary_node_id` 和 `primary_node_title`。历史问答可通过 `POST /api/qa/assignments/reconcile`、传入 `space_id` 幂等补齐。冻结、隐藏或归档节点不作为新归属候选。

新节点先位于合法会话锚点下。后续归属分析根据会话顺序及高维证据提出调整；已有节点移动仍需人工审核。单条问答形成主要节点不代表已完成聚类或已证明结论。

意图判断每批最多 10 对，允许模型以字符串或数字返回局部 ID，严格恢复真实 ID。生长归属预算提高到 6000 tokens。父节点或前序证据不合法的单项建议降为 `uncertain`，保留原树并写入校验理由，其他有效建议继续。语义无效的建议不自动修正为某个父节点；截断 JSON 或缺失整批结果仍报告失败，不自动追加模型请求。

规则整理时，仅收起未承载主要问答、未被会话起点或必要祖先依赖的自动节点。原节点记录和原始思想保留，人工节点与上下文依赖节点保留。

思想空间仅为主思想计算和展示向量；辅助观点仍作为原问答分析文字留存。既有辅助坐标版本保留历史，但不进入 PCA、近邻、生长或重新量化。节点父候选以主思想高维向量及真实会话前序证据计算；缺少主思想向量的历史概念节点可使用节点标题的真实语义编码补齐候选测量，不使用二维屏幕距离代替高维关系。
