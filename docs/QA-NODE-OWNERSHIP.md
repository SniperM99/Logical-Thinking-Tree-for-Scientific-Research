# 按持续研究问题组织问答

每条问答只有一个主要归属节点。解释、追问、质疑、补充证据和同一问题的不同表述优先积累到已有节点。只有用户启动一个具有独立目标、可单独继续研究的问题或验证实验时，才形成新分支。标题变化、出现新关键词、回答中的额外观点不构成新建依据。

## 创建前判断

Java 保存回答及主思想，使用同模型下的真实高维向量召回研究空间中此前存在的有效节点；候选以既有主思想证据及节点语义编码衡量，始终保留当前节点和原始会话入口。隐藏、归档、冻结及祖先冻结节点不准入，后来的节点和未来问答不参与较早问答的判断。

Python `/qa-ownership` 返回三种只读判断：

- `accumulate`：归入已有研究问题，新增直接证据，不创建节点。
- `branch`：必须明确已有父节点、持续研究问题标题、独立目标和实质区别。Java 校验后直接在该父节点创建，原始问答与主思想作为创建证据。
- `uncertain`：暂存本会话前序问答所在的当前有效节点；首次空间会话暂存空间入口。标记“归属待判断”，不创建节点。

只有合法准入候选可成为目标或父节点。已存在同父同标题的节点会复用。模型返回无效或请求失败时，完整问答保留并暂存当前节点；重试只判断归属，不重新生成回答。不自动追加模型请求。

## 上下文和证据

`anchor_id` 是永久原始会话起点。后续回答使用当前研究节点的祖先路径和直接上下文，辅以本会话历史。节点归属在独立 `qa_primary_node` 关系中记录，并携带状态、理由、召回候选及前序依据，不修改原始问答。父节点总结不因子节点生长回写。

既有归属不进行自动批量迁移或合并。此前的结构提案和审计继续保留；历史结构整理需按具体范围进行。

## 思想空间

仅绿色主思想计算向量、核心概念坐标、PCA和高维近邻。辅助观点保留为原问答分析文字，不生成节点、不关联其他节点、不计算向量；数据库向量字段为 NULL，JSON保留空数组。旧辅助坐标保留历史，但不参与现行投影和重新量化。

二维投影只是观察工具，不能代替高维候选度量，也不能证明父子关系。

## 模型成本

回答与思想提取继续合并为一次 DeepSeek 请求；主思想和概念向量由本地模型量化。节点归属另外进行一次有上限的模型请求，不再为每次新问答遍历所有历史问答对、逐批调用意图和事后生长判断。

### 并列分支与深入分支

会话的上一轮归属只表示当前讨论焦点，不能直接决定新节点的父节点。候选携带真实 `parent_id`、祖先路径，历史问答携带 `primary_node_id`；候选召回优先保留当前节点及祖先，再补充语义近邻，最多 32 个。

新分支必须标明 `branch_relation` 和 `reference_node_id`：`sibling` 以已存在的并列对象为参照，父节点取该对象的共同父节点；`child` 以深入研究的对象自身为父节点；`independent` 表示明确切换研究范围。Python 将并列关系解析到共同父节点，Java 在创建之前再次验证真实结构。无法验证时保留问答并暂存待判断，不自动移动历史节点。

例如分类框架下依次研究观测空间、表征空间、决策规划，应生成三个并列子节点；针对表征空间继续开展独立验证实验，则可以在表征空间节点下面生成实验研究分支。时间先后不是父子继承。
