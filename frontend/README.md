# 循序 React 前端

正式架构的前端使用 React 19、TypeScript、Vite，与 Java Spring Boot 权威核心通信。FastAPI AI 服务由 Java 核心协调，浏览器不保存模型密钥，也不直接访问 AI 数据库。

```sh
cd frontend
npm ci
npm run dev
```

开发地址为 `http://127.0.0.1:5173`；Vite 将 `/api` 代理至 `http://127.0.0.1:8080`。生产构建运行 `npm run build`，将 `dist/` 部署到 Java 核心的同源静态资源目录，或由网关将 `/api` 转发至 Java 核心。

React 管理研究空间、节点选择状态及界面组件，`types.ts` 定义领域视图类型，`api.ts` 集中同源 API 请求。已验证的自然树 SVG、档案及操作表单目前保留在隔离的 `legacy.ts` 渲染器中，通过 `controller.ts` 的类型化边界向 React 同步选择状态；后续可逐个迁移为 React 组件，无需改变 API 或研究数据。

运行支持人工报告与真实设备 Agent 派发。行动节点内可选择已注册设备、设置字符串数组命令、工作区内相对目录与超时，派发前展示具体命令；Agent 任务状态及结果每 5 秒刷新。设备心跳以 90 秒内近期在线作为提示，不保证任务一定立即执行。候选方向是启发式模板。未配置真实模型时不会伪造回答。结构操作先产生提案，在历史中审核后执行。原始问答锚点、父路径边界和共同分支来源由 Java 核心验证。

`../xunxu/static` 为本地 Python 验证原型，保留作领域接口回归验证，不是正式架构的生产前端。

## 连续研究会话

顶部「新建会话」从当前研究空间根节点开始；右键研究节点的「新建会话」从该节点开始。原始锚点永久保留。聊天窗口支持连续追问，Enter 发送、Shift + Enter 换行，每轮由服务器生成回答并后台分析，客户端不填写思想标签或上传伪造历史。问答档案可继续历史会话，也可精确跳转对应轮次。逐轮判断提供思想、证据目标、新节点与创建依据。发送中禁止重复提交和关闭；失败保留输入并同步最新轮次。
