# 循序 XunXu

依据《循序自生长研究路径图理论框架 V1.1》构建的早期 SQLite 本地原型，仅用于领域规则演示与回归。最终系统采用根目录 README 规定的 Java / FastAPI / PostgreSQL / React 架构；本原型不是最终业务写入入口。原理论文档保持独立，本实现的范围与限制见下文。

## 启动

需要 Python 3.10 或更新版本，无须安装第三方 Python 包。在本目录运行：

```sh
python3 server.py --port 8765
```

然后打开终端提示的本地地址。研究数据持久保存在 SQLite 中，刷新浏览器不会清空研究记录。请勿将本地服务直接暴露到公网。

## 工作流程

1. 新建研究空间，定义根目标。
2. 在节点档案中启动会话或保存问答；原文、消息位置及原始会话锚点保留。
3. 从问答与研究行动形成思想或行动节点，沿祖先路径获取上下文。
4. 对移动、汇合、叶子合并、冻结、隐藏及独立移植查看预览后确认。
5. 在行动节点登记独立 Run，回传执行事件与结果；失败重试另建 Run。
6. 将资源链接或路径关联研究节点，沿证据链回溯研究过程。

## 可选模型连接

默认可手动录入问答。若需要模型回答，可在启动服务前配置 `XUNXU_API_KEY`、`XUNXU_API_BASE` 与 `XUNXU_MODEL`；密钥只由服务端环境读取，勿写入研究资料或提交到版本库。具体模型连接成功以实际请求结果为准。当前词面坐标使用确定性 256 维哈希、按明确意图标签增量成簇，未接入真实语义嵌入或 HDBSCAN。

## 验证

在本目录运行：

```sh
python3 -m unittest discover -s tests -v
```

领域测试关注上下文隔离、审核失效、结构无环、叶子资格、冻结、移植历史与 Run 幂等，而不是仅验证界面能显示。

## 实现范围与后续验收

本地 SQLite 持久化、研究结构操作与证据归档是真实实现。自动思想识别与推荐需区分启发式规则和已验证的语义模型；离线模式不能等同于高维嵌入或 HDBSCAN 科研验证。设备字段与 Run 记录不能等同于实际远程 Agent 已接收并执行任务。

下一步验收清单：

- [ ] 使用真实科研样本校准思想提取、聚类、既有节点匹配和候选质量。
- [ ] 接入经授权的跨设备任务队列与设备 Agent，验证派发去重、断线重传、取消和结果完整性。
- [ ] 完成真实文献、代码、实验工作流与产物管理的端到端科研样本。
- [ ] 对宽浅树、深链、稠密汇合及大量关联验证自然布局的稳定性与可读性。
- [ ] 校准规模和形态双门槛，再启用自动剪枝建议。
- [ ] 增加账户、权限、备份恢复及部署安全能力后再支持多人或公网使用。
- [ ] 补充完整结构撤销、运行中任务移植、跨边界汇合等复杂操作验收。
- [ ] 第二阶段接入外部 Codex / Claude 事件感知，并保留来源与授权边界。

当前交付适合本机验证核心研究闭环，不能据此宣称 V1.1 全部第一阶段科研智能与跨设备能力已通过验收。
